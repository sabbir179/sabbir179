## Featured portfolio projects

### [RiskLens AI — Risk Intelligence and Evidence Pipeline](https://github.com/sabbir179/AEGIS-RISK)

An independent portfolio project for turning news and RSS evidence into source-linked geopolitical and supply-chain risk assessments.

- Ingests news into raw Bronze data, normalises and deduplicates Silver evidence, and produces Gold risk outputs.
- Uses ChromaDB for evidence retrieval and an analyst–critic workflow to review generated assessments.
- Provides FastAPI endpoints and a Streamlit interface for querying and reviewing results.

**Stack:** Python, SQLAlchemy, SQLite, ChromaDB, LLM APIs, FastAPI, Streamlit.

### [Healthcare Data Platform and Admission Prediction](https://github.com/sabbir179/hospital_operations_analysis)

An independent portfolio project combining data preparation, analytical storage and a machine-learning application across 9,216+ encounter records.

- Transforms raw records into validated Silver datasets and Gold DuckDB marts for patient volume, waiting-time and admission analysis.
- Applies cleaning, type handling, feature derivation and data-quality checks.
- Serves curated data and admission predictions through FastAPI and Streamlit, with Docker configuration and setup documentation.

**Stack:** Python, pandas, SQL, Parquet, DuckDB, scikit-learn, FastAPI, Streamlit, Docker.

### [Healthcare Risk Prediction](https://github.com/sabbir179/healthcare_risk_prediction)

A portfolio study of chronic kidney disease classification, covering data preparation and supervised machine learning. This is an educational project; it is not a clinical tool.
